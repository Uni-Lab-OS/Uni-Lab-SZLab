# 真机接入清单

仓库默认配置只用于离线/测试模式。真机启用必须在受控网络中逐项完成：

1. 为每个 PLC/工站建立不入库的部署覆盖文件，填写 IP、端口、NodeId 映射和凭据。
2. 用只读连接验证 CSV 中全部节点类型、访问级别和 PLC 时钟；禁止先写变量再排查映射。
3. 分别验证工位 ready、home、allow-process、params-written、complete 和 reset 握手。
4. 校准 S01-S11 机械臂产品类型、位置编码、传感器前置条件和抓放完成后的物料状态。
5. 核对 S03/S11 堆栈、S2 枪头、S7 粉罐和 S10 液体试剂 warehouse 的现场位置与容量。
6. 验证 timeout、cancel、disconnect、急停与重启后的 reconcile 流程。
7. 先在 `--test_mode` 运行 Python 工作流，再按单工位、跨工位、整流程顺序解除模拟。
8. 保存经审核的运行日志、PLC 变量快照和物料快照，并由设备负责人批准生产切换。

不得把密码、token、可公网访问的 PLC 地址或跳过联锁的环境变量提交到仓库。
