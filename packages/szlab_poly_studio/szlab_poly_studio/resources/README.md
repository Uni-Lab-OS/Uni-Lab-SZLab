# SZLab resource mesh assets

Drop per-material runtime models here, for example:

```text
resources/szlab_beaker_500ml/model.glb
resources/szlab_sample_vial_250ml/model.glb
```

Paths must match `model_manifest.yaml` `representations.*.entry` values.
2.5D board rendering does **not** require these files; they are for 3D only.
